FATMA BAYOMI — PORTFOLIO WEBSITE

Files:
- index.html: responsive, self-contained portfolio website.

To preview:
1. Extract the ZIP.
2. Open index.html in a browser.

To publish and get a public URL:
- Upload the folder/repository to GitHub.
- Enable GitHub Pages in the repository Settings > Pages.
- Your public website URL will be shown there.

Before publishing:
- Replace the LinkedIn placeholder link with your actual LinkedIn profile URL.
- Check the phone number and project links.
- The portfolio content is based on the supplied CV.
